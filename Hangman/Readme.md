# CodeAlpha Hangman Game 🎮

A simple **text-based Hangman game built using Python** as part of my CodeAlpha Python Internship.

## 📌 About the Project

The player has to guess a randomly selected word **one letter at a time**.

The game provides a maximum of **6 incorrect guesses**. Each correct guess reveals the letter in its correct position, while an incorrect guess moves the player closer to the Hangman.

## ✨ Features

* Randomly selects a word from a predefined list
* Allows the player to guess one letter at a time
* Displays correctly guessed letters
* Tracks incorrect guesses
* Maximum of 6 incorrect guesses
* Prevents repeated guesses
* Displays Hangman stages in the console
* Shows the final result when the game ends

## 🎮 How to Play

1. Run the Python program.
2. A random word will be selected.
3. Enter one letter at a time.
4. Correct letters are revealed.
5. Incorrect guesses increase the Hangman count.
6. You have a maximum of 6 incorrect guesses.
7. Guess the complete word before all attempts are used to win.
